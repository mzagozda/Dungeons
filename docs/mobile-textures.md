# Mobile texture variants

The desktop source imports stay lossless. Android and iOS export hooks select native ETC2 variants generated in an isolated asset-only Godot project; they do not temporarily change the game project's compression mode. ETC2 is the chosen mobile member of the specification's ETC2/ASTC family. ASTC is not generated by this profile, and physical quality/performance acceptance remains pending.

`tools/check_imports.py` now covers all 54 PNGs under `game/textures/` and `game/models/`, including the textures extracted from GLB files. The older check covered only the atlas and direct model sheets, missing the actual GLB character textures. Characters, arrows and pickup sheets have no mipmaps; terrain/props have mipmaps. All have desktop `compress/mode=0` and `detect_3d/compress_to=0`. Disabling detection matters because Godot's [3D texture callback](https://github.com/godotengine/godot/blob/4.4.1-stable/editor/import/resource_importer_texture.cpp#L122) can otherwise automatically enable VRAM compression and mipmaps after the source check. PNG pixels/GLB models and their authored palette remain unchanged; the import policy is deliberately corrected.

`tools/Build-MobileTextureVariants.ps1 -ProjectDirectory <new-folder>` copies the 54 textures and their UIDs into an isolated project, applies explicit mobile import options and runs the pinned native importer. The project enables `import_etc2_astc`; normal-quality VRAM compression produces [native ETC2 `.ctex` data](https://github.com/godotengine/godot/blob/4.4.1-stable/editor/import/resource_importer_texture.cpp#L651). The desktop host also generates its own S3TC cache, as required by Godot; that data is never packaged by this hook. The standalone native audit loads every ETC2 resource and checks actual GPU image format, size, mipmap policy and data length. Python verifies original source/import hashes again before sealing a new manifest. Existing projects/manifests are refused.

`game/addons/editor_export/mobile_textures.gd` uses the normal export-file hook for Android/iOS only. It verifies each original PNG/import hash and each generated payload/remap hash, requires complete source coverage, then packages the native ETC2 data with an unconditional remap and preserved UID. An unconditional remap prevents a mobile driver from choosing an unpackaged host format. Fonts, UI, catalogue previews and editor icons are outside this conversion boundary. Desktop exports retain the original lossless resources; source materials and nearest shader filters remain authoritative.

`tools/Export-M0.ps1` builds a fresh profile automatically for mobile, requires a clean native export log and the complete compression marker, then checks actual APK bytes and remaps. It also mounts the real APK resources in a fresh Godot process, resolves all 54 source textures and instantiates all 21 referenced model variants, checking 80 material slots for ETC2 data. The associated `.apk.textures.json` points to that immutable profile and its native/package audit evidence. The normal and Low Android presets use the same ETC2 policy. The iOS hook is configured; no Mac/iOS export or execution is claimed.

```powershell
# Activate the local toolchain and install the pinned asset dependencies:
. ./tools/Common.ps1
python -m pip install -r tools/requirements.txt
# Pinned desktop importer/auditor, independently of a package build:
./tools/Build-MobileTextureVariants.ps1 -ProjectDirectory artifacts/mobile-textures/my-new-profile
# Full exports also run this automatically:
./tools/Export-M0.ps1 -Platform Android
./tools/Export-M0.ps1 -Platform Android -Low
# Real exporter rejection tests, preserving the original profile:
$profile = (Get-Content artifacts/android/block_dungeons.apk.textures.json -Raw | ConvertFrom-Json).profileDirectory
./tools/Test-MobileTextureExport.ps1 -ProfileDirectory $profile
```

Eight pure tests cover actual/extracted texture classification, missing/duplicate import options, explicit auto-detection policy, read-only source copying, native audit coverage, stale sources, single-format remaps, changed package bytes and desktop-variant rejection. Four actual exporter cases reject missing profiles, changed source identity, changed payload bytes and missing textures. Godot itself returns zero for these `push_error` cases, so the canonical wrapper also rejects engine errors and requires the positive completion marker. The tests reject unrelated engine errors; they do not allowlist the pinned `_EDITOR_GET` teardown diagnostic. CI includes the pure cases and Android exporter rejections, with evidence uploaded even on failure.

Local evidence is under `artifacts/mobile-textures/`. Normal and Low APKs contain exactly the audited native data: 54 textures, **1,492,936 compressed GPU image bytes**, no duplicate lossless/S3TC/BPTC variants, and correct character/terrain mipmaps. The real model material bindings also pass. `desktop-native-audit.json` verifies every original desktop resource is uncompressed and has the expected mipmaps. `export-boundaries/result.json` records the four rejected native exports and unchanged original profile. Two early isolated import failures are preserved (`native-import-initial.log` and `native-export-ready/native-import.log`); the latter contains the known intermittent pinned `_EDITOR_GET` diagnostic and was rejected. Strict clean retries/fresh builds and complete audits pass; no error signature was waived.

The inspected `mobile-terrain-bridge.png` renders actual APK textures through the real scene on desktop Compatibility/OpenGL. Its five-second capture reports p95 0.885 ms, p99 1.064 ms, at most 58 draws/21,470 triangles and 12,375,479 texture bytes on RTX 3060. This is a desktop check of the packaged resources and material bindings. It does not certify a phone GPU, compression quality on the reference devices, battery/thermal limits or visual sign-off. No visual/replay baseline was approved or replaced, and no device operation was performed.

The final texture-inclusive `Test-M9.ps1 -Rendered` run passes at `artifacts/m9/gate-25c109767f5c4012803aa1d4810a9dd1/`, transcript `artifacts/mobile-textures/combined-gate.log`: 447 normal/434 coverage cases, 98.31% Core coverage, 86 headless Godot cases, 34 native UI/four effects/nine editor cases per backend, 36 pure Python contracts, 22 launch/process checks and 22 repeated Mobile scenarios with zero mismatched pixels.
