Specification clarifications:

- §20.4's original replay sketch omitted an end boundary for the last RLE run. The documented v1 wire format now includes `tickCount`, `initialHash` and optional `duration`; optional `tickHashes` supports exact first-divergence reporting. No committed gameplay golden was changed.
- §10.8 requires unknown properties to be warnings, while Appendix B closes several objects. Runtime schema checks keep the types/ranges/local refs/conditional structure and report those unknown keys as LVL0100 warnings; property bags remain closed errors. The evaluator implements the vocabulary used by the embedded v1 schema; it is not advertised as a general external-schema engine.
- §10.9 assigns LVL1030 and LVL1031 the same all-gates-open reachability predicate. Unreachable exits currently emit both; the error prevents play. Therefore those two negative checks share a fixture rather than claiming isolated single-code outcomes.
