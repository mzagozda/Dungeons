## AnimationTree follow-up — 2026-10-27

`ActorPosePolicy` reads Core snapshots without mutation or allocation. It selects death/emerge/roll/stagger/hit/action/walk/idle in priority order and derives phase ages from integral timers plus interpolation alpha. Melee clips are split into windup/active/recovery segments and each segment scales to the current combo's duration, including cooldown multipliers. Walk playback uses actual velocity relative to 4.5 m/s. Ranged aim/fire use their own authored clips and resolved timings.

Each actor owns a manually advanced AnimationTree and playback parameters. Definition-specific graph resources are shared; AnimationPlayer supplies imported clips and never plays concurrently. Normal transitions blend for 30 ms; same-state restarts and rapid interrupts immediately adopt the latest snapshot instead of queuing behind a fade. A phase-entry seek includes the snapshot age and is not advanced twice. Pool deactivation/reset clears prior roll/freeze state. The outer TimeScale implements 40/70 ms presentation-only hit-stop; per-state scales cannot lengthen transition fades. Reduce motion bypasses freezing. Damage flash now expires against the presentation clock rather than the number of interpolation calls.
