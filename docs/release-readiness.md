## Android package audit

```powershell
$env:ANDROID_HOME = 'C:/Program Files (x86)/Android/android-sdk'
$env:JAVA_HOME = 'C:/Projects/dungeons/.toolchain/jdk17/jdk-17.0.20.1+1'
./tools/Test-AndroidRelease.ps1 -ApkPath artifacts/android/block_dungeons.apk -EvidenceDirectory artifacts/release/my-new-audit
# For a publisher-signed candidate, also supply the expected public certificate fingerprint:
# -ReleaseCertificateSha256 <64 hexadecimal characters>
```

The script runs the installed Android build-tools `aapt` and `apksigner` against the actual APK, retaining their raw output. It reads every packaged arm64 ELF program header, checks all PT_LOAD segment alignments/congruence, checks the actual ZIP data offset of uncompressed libraries, verifies min/target SDK, debuggability, APK size and the expected publisher certificate. A valid signature from an unidentified key does not count as publisher signing. The Python parser never executes or extracts a native library. It rejects malformed ELF headers/extents, unexpected ABIs, duplicate/unsafe members and missing native libraries. Existing evidence is preserved.

This is an APK prerequisite check. Even a passing report leaves `storeSubmissionReady`, `aabAcceptance` and `physical16KbAcceptance` false. A store candidate still requires a signed AAB, bundletool-generated APK/config validation, store assets/metadata and device execution. Debug APK export remains usable independently of the release gate.

Policy checked on **2026-10-27**: [Google Play requires API 36 for new mobile apps and updates from 2026-08-31](https://support.google.com/googleplay/android-developer/answer/11926878). The optional extension is account-specific and is not assumed here. [Android's current page documents ELF/ZIP 16 KB requirements and an update deadline of 2027-02-01](https://developer.android.com/guide/practices/page-sizes). This supersedes the date in the older 2025 announcement originally cited here. The audit remains a technical 16 KB compatibility gate; it does not infer account-specific submission eligibility from that deadline. Changing ZIP padding cannot repair a 4 KB ELF LOAD alignment.
